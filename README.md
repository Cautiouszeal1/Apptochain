# Apptochain

Token management, liquidity monitoring and AI agents for Web3 project teams. Launching on BNB Chain, with Base and Ethereum next.

## What's in this repo

- `index.html`: the full Apptochain website and dashboard in one file
  - Landing page that explains Apptochain, the AI agents and the roadmap
  - Wallet connect (MetaMask, Trust Wallet, Binance Wallet, OKX and other browser wallets) or watch-only address
  - Dashboard: liquidity pools, treasury wallets, vesting schedules, alert rules
  - On-chain reads through the connected wallet: native balances, token balances, total supply
  - How-to guide and FAQ

## Run it

Open `index.html` in a browser, or publish it with GitHub Pages or Vercel.

## Notes

- Apptochain is read-only. It never requests a signature, a transaction or a spending approval.
- Workspace data is saved in the visitor's browser.
- AI agents launch with Phase 2 of the roadmap.
- Apptochain has no token. Nothing on this site is financial advice.
