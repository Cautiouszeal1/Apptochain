# AppToChain Agents
On-chain monitoring agents for BNB Smart Chain — rule engine, live alerts, tokenomics (PDF + Excel), whitepaper (PDF + MD), pitch deck (PPTX), team, roadmap. Pure static site — no serverless functions needed.

## Deploy
Push index.html (+ this README) to GitHub → Vercel auto-deploys. Framework "Other", no build command, Root Directory empty.

## Optional config in index.html
- WALLETCONNECT_PROJECT_ID — free from cloud.reown.com (enables WalletConnect QR)
- EMAILJS_CONFIG — enables email alerts

## Before going live
Replace the placeholder team names in the Team section with real, verifiable members.
